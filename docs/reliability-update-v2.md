# 大版本可靠性更新计划（回合超时专项）

## 本轮目标

- 降低出牌、单位动作和导航确认的无效等待，减少游戏回合超时。
- 保留两帧手牌稳定、合法目标确认、失败封锁和安全停机，不以盲点坐标换取速度。
- 仅做合规的稳定性改进：固定安全节奏、有限重试、异常退避和诊断日志；不实现随机人类化、反作弊探测、检测规避或 AFK 绕过。

## 已实现的第一阶段参数

- `cardPlayPaceMs`：750 → 600
- `unitActionPaceMs`：650 → 500
- `endTurnPaceMs`：1100 → 800
- `navPaceMs`：1800 → 1200
- `playCardConfirmTimeoutMs`：2400 → 1600
- `unitActionConfirmTimeoutMs`：10000 → 4500
- `deploymentSettleWaitMs`：550 → 400
- `maxPlayAttemptsPerTurn`：3 → 2
- HQ 搜索步长增大，减少每帧候选扫描。
- OCR 瞬态空结果重试等待：500ms → 120ms。
- 导航点击确认上限从 `navPaceMs * 3.9` 降至 `* 2.8`。

## 风险与验证边界

参数下调可能在低性能设备或网络抖动时过早判定动作失败。必须先通过离线回放，再在训练模式进行有界实机验证；未有实机证据前，不宣称完整对局闭环已通过。

## 当前未实现

- 回合剩余时间感知及按时间预算的安全结束回合。
- 对手回合、同场景、连续动作失败等超时分支的独立回归测试。
- 出牌/单位动作确认耗时的逐动作统计指标。
