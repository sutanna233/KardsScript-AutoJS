# Auto.js 说明

## 边界

- `autojs/` 是项目唯一维护的实现，使用 Auto.js6 的无障碍与 `requestScreenCapture`；
- 默认只读。游戏不在前台、页面置信度不足、商店/卡牌收藏页或缺少视觉合法目标时均不得操作。

## 当前迁入内容

- 已迁入经过 PNG 样本校验的八类页面锚点：主页、模式菜单、卡组列表、卡组详情、卡牌收藏、商店、换牌、战斗；
- 回合识别只能在 `BATTLE` 页面确认后产出；
- 不包含盲目的多步骤匹配点击，也不包含出牌、攻击、单位操作的固定目标回退。

## 实机验证顺序

1. 安装并授权 Auto.js，先运行 `observe`；
2. 验证主菜单、训练卡组选择、换牌、我方/敌方回合日志；
3. 采集结算、重连及不同手牌数量截图；
4. 实现“选中源 → 截图 → 仅从高亮目标执行”的 `target-probe` 后，再单独开放动作。
